# Petty Suggestions

This is the suggestion box for [Petty FOSS](https://github.com/petty-foss-dev).

Have an app idea? Found somebody charging monthly for a crappy AI wrapper? Want a free, open-source version of an app you're actually using? [Open a suggestion](https://github.com/petty-foss-dev/Petty-Suggestions/issues/new?template=app-suggestion.md).

Send me the app or Reddit post if there is one, what it does, and what you'd want a free version to do. I'll look for an existing open-source app first. If somebody already made a good one, I'll point you to it and credit them. If I can't find one, I'll make it.
